# 5.2 零基础 AI 前端开发指南

## 1. 这份指南解决什么问题
- 你不会写前端代码，也能用 AI 工具把页面做出来。
- 你不知道如何提需求给 AI，这里提供可直接复制的提示词模板。
- 你不知道怎么验收页面是否可用，这里给出检查清单。

## 2. 准备环境（一次性）
1. 安装 Node.js 20 LTS。
2. 安装 pnpm：`npm i -g pnpm`。
3. 在仓库根目录创建前端项目目录 `frontend/`。
4. 启动后端 FastAPI，确保 `http://127.0.0.1:8000/docs` 可访问。

## 3. AI 协同的工作方式
- 规则 1：一次只让 AI 做一件事。
- 规则 2：先要“页面骨架”，再要“数据联调”，最后要“样式细化”。
- 规则 3：每次改动后都让 AI 给出“验证步骤”。
- 规则 4：所有接口都通过 `src/lib/api` 调用，不直接在页面写请求。

## 4. 建议开发顺序（新手友好）
1. 先做页面框架：侧边栏、顶部栏、路由。
2. 再做只读页面：项目列表、任务列表。
3. 再做可提交页面：创建任务、创建导出。
4. 最后做复杂页面：任务详情（日志 + 指标 + 报告）。

## 5. 可直接复制的 AI 提示词模板

### 5.1 初始化项目
```text
你是资深前端工程师。请在 frontend 目录初始化 Next.js 14 + TypeScript + Tailwind + shadcn/ui 项目。
要求：
1) 使用 pnpm。
2) 配置 ESLint 和 Prettier。
3) 增加 .env.example，包含 NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000。
4) 创建基础布局：左侧导航 + 顶部栏。
5) 输出你创建/修改的文件清单。
```

### 5.2 生成 API Client
```text
请根据后端统一响应结构生成前端 API 客户端。
后端成功响应: { ok: true, data: ... }
后端失败响应: { ok: false, error: { code, message, details, type } }
要求：
1) 在 src/lib/api 创建 request.ts 和各模块 client。
2) 统一处理错误并抛出可读信息。
3) 给出每个函数的 TypeScript 类型。
```

### 5.3 生成页面（以任务列表为例）
```text
请实现任务列表页面：/jobs
要求：
1) 使用 TanStack Query 拉取数据。
2) 状态包含 loading / empty / error / success。
3) 表格列：job_id、status、task_type、updated_at。
4) 点击行跳转到 /jobs/[jobId]。
5) 使用 shadcn/ui 组件，不要直接写原生样式。
```

### 5.4 生成表单（以创建任务为例）
```text
请实现创建任务表单。
要求：
1) 使用 React Hook Form + Zod。
2) 字段：job_id, task_type, dataset_version_id, resources.gpu_count。
3) 前端校验失败时给出中文提示。
4) 提交成功后跳转到任务详情页。
```

### 5.5 生成 E2E 测试
```text
请用 Playwright 写 1 条冒烟用例：
流程：进入任务列表 -> 打开创建任务表单 -> 提交 -> 看见新任务。
要求：
1) 选择器稳定，不依赖样式 class。
2) 失败时截图。
3) 输出运行命令与预期结果。
```

## 6. 页面验收清单（每个页面都要过）
- 能打开：路由可访问，不白屏。
- 能看见：加载、空状态、错误态都可见。
- 能操作：按钮、输入、提交行为符合预期。
- 能提示：错误信息对非技术人员可读。
- 能回退：失败后可以重试。
- 能追踪：关键操作在浏览器网络面板可看到请求。

## 7. 常见问题与处理
- 问题：AI 一次改太多，项目跑不起来。
  - 处理：要求 AI 分 3 步提交：初始化、页面、联调。
- 问题：接口字段对不上。
  - 处理：让 AI 先打印后端响应，再更新前端类型。
- 问题：样式混乱。
  - 处理：规定只用 design token 和 shadcn 组件。
- 问题：请求到处写。
  - 处理：强制所有请求集中在 `src/lib/api`。

## 8. 最低可用交付标准（MVP）
- 页面：项目、数据集、任务、任务详情、Proposal、导出。
- 能力：可查询、可创建、可查看状态。
- 质量：至少 5 条 E2E 冒烟测试通过。
