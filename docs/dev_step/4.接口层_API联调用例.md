## 3. 项目与 KPI 配置

说明：当前实现没有项目创建 HTTP 端点；项目需要在服务容器中预置后再调用 KPI 接口。

### 3.1 更新 KPI 配置
```bash
curl -s -X PUT "http://127.0.0.1:8000/projects/proj-1/kpi-config" \
  -H "Content-Type: application/json" \
  -d '{
    "primary_kpi": "business_kpi",
    "threshold": 0.8,
    "weights": {"eval": 0.7, "deploy": 0.3},
    "deploy_constraints": [
      {"metric": "latency_p95_ms", "operator": "<=", "value": 30}
    ]
  }'
```

成功响应示例：
```json
{
  "ok": true,
  "data": {
    "project_id": "proj-1",
    "primary_kpi": "business_kpi",
    "threshold": 0.8,
    "weights": {"eval": 0.7, "deploy": 0.3},
    "deploy_constraints": [
      {"metric": "latency_p95_ms", "operator": "<=", "value": 30}
    ]
  }
}
```

失败响应示例（项目不存在）：
```json
{
  "ok": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "project not found",
    "details": [],
    "type": "business_error"
  }
}
```

### 3.2 查询 KPI 配置
```bash
curl -s "http://127.0.0.1:8000/projects/proj-1/kpi-config"
```

## 4. 数据集与场景标签

### 4.1 导入数据集版本
```bash
curl -s -X POST "http://127.0.0.1:8000/datasets/ds-1/versions/import" \
  -H "Content-Type: application/json" \
  -d '{"version": 1, "manifest_uri": "s3://bucket/v1.json"}'
```

成功响应示例：
```json
{
  "ok": true,
  "data": {
    "dataset_version_id": "ds-1:v1",
    "dataset_id": "ds-1",
    "version": 1,
    "manifest_uri": "s3://bucket/v1.json",
    "frozen": false
  }
}
```

### 4.2 冻结数据集版本
```bash
curl -s -X POST "http://127.0.0.1:8000/datasets/ds-1/versions/1/freeze"
```

重复冻结失败示例：
```json
{
  "ok": false,
  "error": {
    "code": "CONFLICT",
    "message": "dataset version already frozen",
    "details": [],
    "type": "business_error"
  }
}
```

### 4.3 写入场景标签
```bash
curl -s -X PUT "http://127.0.0.1:8000/datasets/versions/ds-1:v1/scene-labels" \
  -H "Content-Type: application/json" \

    "labels": [

        "image_id": "img-2",
```


## 5. 任务编排与观测

### 5.1 创建任务
```bash
curl -s -X POST "http://127.0.0.1:8000/jobs" \
  -H "Content-Type: application/json" \
  -d '{
    "job_id": "job-1",
    "task_type": "training",
    "dataset_version_id": "ds-1:v1",
    "resources": {"gpu_count": 1}
  }'
```

### 5.2 查询任务状态
```bash
curl -s "http://127.0.0.1:8000/jobs/job-1"
```

### 5.3 启动任务
```bash
curl -s -X POST "http://127.0.0.1:8000/jobs/job-1/start" \
  -H "Content-Type: application/json" \
  -d '{"gpu_id": "0"}'
```

### 5.4 追加与查询日志
```bash
curl -s -X POST "http://127.0.0.1:8000/jobs/job-1/logs" \
  -H "Content-Type: application/json" \
  -d '{"message": "train step 1"}'

curl -s "http://127.0.0.1:8000/jobs/job-1/logs?page=1&page_size=20"
```

### 5.5 写入与查询指标
```bash
curl -s -X POST "http://127.0.0.1:8000/jobs/job-1/metrics" \
  -H "Content-Type: application/json" \
  -d '{"ts": 1000, "values": {"loss": 0.9, "lr": 0.001}}'

curl -s "http://127.0.0.1:8000/jobs/job-1/metrics?start_ts=900&end_ts=2000"
```

## 7. Proposal 工作流

### 7.1 校验候选实验
```bash
curl -s -X POST "http://127.0.0.1:8000/proposals/validate" \
  -H "Content-Type: application/json" \
  -d '{
    "analysis_report": "summary",
    "next_experiments": {
      "experiments": [
        {
          "name": "exp-1",
          "changes": [{"field": "lr", "from": 0.001, "to": 0.0005}],
          "expected": "higher kpi",
          "evidence_refs": ["eval_report.overall.business_kpi"]
        }
      ]
    }
  }'
```

成功响应示例：
```json
{
  "ok": true,
  "data": {
    "accepted": 1
  }
}
```

```bash
curl -s -X POST "http://127.0.0.1:8000/proposals/create-from-candidate" \
  -H "Content-Type: application/json" \
  -d '{
    "candidate": {
      "name": "exp-1",
      "changes": [{"field": "lr", "from": 0.001, "to": 0.0005}],
      "expected": "higher kpi",
      "evidence_refs": ["eval_report.overall.business_kpi"]

    "who": "alice",
    "when": "2026-03-06T10:00:00Z",
    "confirmed": true,
    "idempotency_key": "idem-1"
  }'
```

响应示例：
```json
{
  "ok": true,
```

## 9. 常见错误码示例
- `VALIDATION_ERROR`：请求参数非法或缺失
- `NOT_FOUND`：资源不存在
- `CONFLICT`：资源状态冲突
- `RESOURCE_LOCKED`：GPU 资源冲突
- `DATA_INVALID`：业务前置条件不满足
- `EXPORT_FAILED`：导出执行失败
- `LLM_GATEWAY_ERROR`：LLM 调用失败（Provider 不可用/超限/超时）
- `KNOWLEDGE_IMPORT_FAILED`：知识导入失败
