# 4.接口层 API 路由清单

## 1. 说明
- Web 框架：FastAPI
- 应用入口：`src/web/app.py`
- 路由定义：`src/web/routes.py`
- 业务适配层：`src/api/*_routes.py`
- 联调用例：`docs/dev_step/4.接口层_API联调用例.md`

统一响应结构：
- 成功：`{"ok": true, "data": {...}}`
- 失败：`{"ok": false, "error": {"code": "...", "message": "...", "details": [], "type": "..."}}`

统一状态码映射（`src/web/routes.py`）：
- `NOT_FOUND -> 404`
- `CONFLICT -> 409`
- `SYSTEM_ERROR -> 500`
- 其他错误默认 `400`

## 2. 健康检查

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| GET | `/health` | 服务健康状态 | 无（直接返回） |

## 3. 项目与 KPI 配置

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| GET | `/projects/{project_id}/kpi-config` | 查询项目 KPI 配置 | `ProjectRoutes.get_project_kpi_config` |
| PUT | `/projects/{project_id}/kpi-config` | 更新项目 KPI 配置 | `ProjectRoutes.put_project_kpi_config` |

PUT 请求体关键字段：
- `primary_kpi: str`
- `threshold: number`
- `weights.eval: number`
- `weights.deploy: number`
- `deploy_constraints[]: {metric, operator, value}`

## 4. 数据集与场景标签

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| POST | `/datasets/{dataset_id}/versions/import` | 导入数据集版本 | `DatasetRoutes.import_dataset_version` |
| POST | `/datasets/{dataset_id}/versions/{version}/freeze` | 冻结数据集版本 | `DatasetRoutes.freeze_dataset_version` |
| PUT | `/datasets/versions/{dataset_version_id}/scene-labels` | 批量写入/更新场景标签 | `DatasetRoutes.upsert_scene_labels` |
| GET | `/datasets/versions/{dataset_version_id}/scene-coverage` | 查询场景覆盖率统计 | `DatasetRoutes.get_scene_coverage` |

请求要点：
- 场景标签请求体格式：`{"labels": [ ... ]}`
- 覆盖率查询参数：`dimensions`（可多值）

## 5. 任务编排与观测

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| POST | `/jobs` | 创建训练任务 | `JobRoutes.create_job` |
| GET | `/jobs/{job_id}` | 查询任务状态 | `JobRoutes.get_job` |
| POST | `/jobs/{job_id}/start` | 启动任务并绑定 GPU | `JobRoutes.start_job` |
| POST | `/jobs/{job_id}/logs` | 追加任务日志 | `JobRoutes.append_log` |
| GET | `/jobs/{job_id}/logs` | 分页查询日志 | `JobRoutes.get_logs` |
| POST | `/jobs/{job_id}/metrics` | 写入指标点 | `JobRoutes.record_metric` |
| GET | `/jobs/{job_id}/metrics` | 按时间窗口查询指标 | `JobRoutes.get_metrics` |

请求要点：
- 创建任务体需包含 `resources.gpu_count > 0`
- 日志分页参数：`page`, `page_size`
- 指标窗口参数：`start_ts`, `end_ts`

## 6. 分析产物查询

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| GET | `/jobs/{job_id}/artifacts/eval-report` | 查询 `eval_report` | `AnalysisRoutes.get_eval_report` |
| GET | `/jobs/{job_id}/artifacts/evidence-pack` | 查询 `evidence_pack` | `AnalysisRoutes.get_evidence_pack` |
| GET | `/jobs/{job_id}/artifacts/analysis-report` | 查询 `analysis_report` | `AnalysisRoutes.get_analysis_report` |

查询参数：
- 以上四个接口都需要 `run_id`

## 7. Proposal 工作流

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| POST | `/proposals/validate` | 校验候选实验 | `ProposalRoutes.validate_proposals` |
| POST | `/proposals/create-from-candidate` | 用户确认后创建任务 | `ProposalRoutes.create_from_proposal` |

请求要点（创建接口）：
- 必填：`candidate`, `baseline_job_id`, `who`, `when`, `confirmed=true`
- 可选：`idempotency_key`（用于幂等复用）

## 8. 导出与部署基准

| 方法 | 路径 | 说明 | 适配层方法 |
|---|---|---|---|
| POST | `/exports` | 创建导出任务 | `ExportRoutes.create_export` |
| GET | `/exports/{export_id}` | 查询导出状态 | `ExportRoutes.get_export_status` |
| GET | `/exports/{export_id}/deploy-benchmark` | 查询部署基准 | `ExportRoutes.get_deploy_benchmark` |

请求要点：
- 导出创建体：`job_id`, `run_id`, `backend`
- 当前支持 `backend=tensorrt`
