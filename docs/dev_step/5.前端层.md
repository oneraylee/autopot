## 2. 前端开发目标
- 构建 Web UI，覆盖产品 MVP 核心闭环。
- 提供非技术用户可操作的页面流：查看状态、触发动作、理解结果。
- 与 FastAPI 契约一致，保证联调可复现。

## 3. 阶段计划（Frontend Plan）

### Phase F1: 工程初始化与基础框架（1-2 天）
- 目标：建立可持续开发的前端工程骨架。
- 交付物：
  - `frontend/` 项目（Next.js + TS + Tailwind + shadcn/ui）
  - 全局布局（侧栏 + 顶栏 + 内容区）
  - API 基础客户端与错误处理
- 验收：
  - `pnpm dev` 可启动
  - 至少 3 个空页面可访问（projects/datasets/jobs）

### Phase F2: 核心读操作页面（2-3 天）
- 目标：先打通“可查看”链路。
- 页面：
  - 项目 KPI 配置查看
  - 数据集版本与场景覆盖率查看
  - 任务列表与任务详情（状态/日志/指标）
- 验收：
  - 所有页面具备 loading/empty/error 三态
  - 可完成从列表到详情的导航

### Phase F3: 核心写操作页面（2-3 天）
- 目标：打通“可发起动作”链路。
- 页面与动作：
  - KPI 配置更新
  - 数据集导入/冻结
  - 创建训练任务、启动任务
  - Proposal 校验与确认创建
  - 创建导出任务
- 验收：
  - 表单校验完整
  - 成功与失败反馈明确

### Phase F4: 报告与联调增强（2 天）
- 目标：支持决策页面与联调稳定性。
- 页面：
  - Eval Report / Evidence Pack / Analysis Report / Next Experiments
  - 导出状态与 Deploy Benchmark
- 验收：
  - 关键流程端到端可操作
  - 与后端联调脚本口径一致

### Phase F5: 质量与发布准备（1-2 天）
- 目标：可演示、可回归、可交付。
- 交付：
  - E2E 冒烟用例（Playwright）
  - 页面可用性问题修复
  - 发布说明与运行手册
- 验收：
  - 5 条以上 E2E 通过
  - 演示流程一次走通

### Phase F6: 知识系统管理页面（2-3 天）
- 目标：支持知识导入、技能卡片浏览与审核、检索测试。
- 页面：
  - 知识源列表与注册
  - 文档导入（支持本地文件 + URL）与解析状态查看
  - 技能卡片列表（按 category/layer/task_type/maturity 筛选）
  - 技能卡片详情（条件、动作、收益代价、关系图、来源证据）
  - 技能抽取审核页（确认/修改/拒绝候选技能）
  - 冲突检测结果查看与人工仲裁
  - Skill Taxonomy 树状浏览
- 验收：
  - 可完成一次完整导入流程（注册源 → 导入 → 查看候选 → 审核发布）
  - 技能卡片筛选和详情可正常渲染

### Phase F7: LLM Gateway 设置页面（1 天）
- 目标：支持查看 Gateway 状态与成本监控。
- 页面：
  - Provider 列表（名称、模型、状态）
  - 用量报表（按 call_type/provider/model 分组，显示 token 数、成本）
  - 调用日志列表（分页，支持按 call_type/provider/status 筛选）
- 验收：
  - Provider 列表可正常加载
  - 用量报表图表可渲染

## 4. 页面清单（MVP）
- `/projects`：项目列表
- `/projects/[id]/kpi-config`：KPI 配置查看/更新
- `/datasets`：数据集列表
- `/datasets/[id]`：版本、冻结、覆盖率
- `/jobs`：任务列表
- `/jobs/[id]`：状态、日志、指标、产物
- `/proposals`：候选实验校验与确认
- `/exports`：导出创建与状态查询
- `/knowledge`：知识源列表与注册
- `/knowledge/documents`：文档导入与状态
- `/knowledge/skills`：技能卡片列表与筛选
- `/knowledge/skills/[id]`：技能详情与关系图
- `/knowledge/review`：抽取审核与冲突仲裁
- `/settings/llm-gateway`：Provider 列表、用量报表、调用日志

## 5. 与后端接口映射（关键）
- KPI：`GET/PUT /projects/{project_id}/kpi-config`
- 数据集：导入、冻结、标签、覆盖率
- 任务：创建、查询、启动、日志、指标
- 产物：eval/evidence/analysis/next-experiments
- Proposal：validate/create-from-candidate
- 导出：create/status/deploy-benchmark
- 知识系统：sources/documents/techniques/retrieval/outcomes（见 API 路由清单 § 9）
- LLM Gateway：providers/usage/call-logs（见 API 路由清单 § 10）

## 6. 风险与应对
- 风险：前端字段与后端契约漂移
  - 应对：OpenAPI 生成类型 + 每周契约回归
- 风险：新手过度依赖 AI 导致结构失控
  - 应对：强制模块目录规范 + Code Review 清单
- 风险：页面可用性不稳定
  - 应对：每个页面必须包含 loading/empty/error 三态

## 7. DoD（Definition of Done）
- 功能：MVP 页面与动作完整可用，知识管理与 Gateway 页面可基本操作。
- 质量：ESLint/Vitest/Playwright 全绿。
- 文档：前端启动、联调、验收说明齐全。
- 体验：非开发人员可按文档完成一次端到端联调（含知识导入流程）。
