## 4. Verification（验证标准）
- 开发顺序固定为：`Common库 -> 数据层 -> LLM Gateway -> 知识系统 -> 业务逻辑层(含集成) -> 接口层 -> 前端层`。
  - LLM Gateway 在数据层之后开发（需要 `llm_call_log` 仓储），在业务逻辑层之前就绪（AgentService 需经由 Gateway 调用 LLM）。
  - 知识系统依赖 Gateway + 数据层（知识表群），在 AgentService 集成之前完成核心服务。
  - 业务逻辑层中 AgentService / EvidencePackBuilder 在集成阶段引入知识上下文注入。
- 每层均具备可独立执行的最小测试集合，且不依赖更上层代码。
- 每层均有明确 DoD：测试通过、接口契约稳定、关键错误码可观测。
