## 2. TDD Implementation Steps（TDD 执行步骤）
- **Step 3.1: 实现 DatasetService（统计与质量检查）**
  - `Task`: 计算类别分布、空图比例、目标尺寸分布、场景覆盖率。
  - `Test File`: `tests/services/test_dataset_service.py`
  - `Impl File`: `src/services/dataset_service.py`
  - `Checklist`:
    - [ ] 编写失败的单元测试 (Red)
    - [ ] 实现最小代码通过测试 (Green)
    - [ ] 抽取可复用统计函数 (Refactor)

- **Step 3.2: 实现 JobService（状态机 + 资源锁）**

## 3. Verification（验证标准）
- 业务层测试覆盖率 ≥ 80%。
- 训练主流程可通过服务级集成测试：创建任务 → 训练完成 → 评估完成 → 证据包生成。
- Agent 输出候选实验可通过 schema 与审计引用校验，且默认不触发自动建任务。
