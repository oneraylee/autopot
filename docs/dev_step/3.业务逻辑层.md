## 3. Verification（验证标准）
- 业务层测试覆盖率 ≥ 80%。
- 训练主流程可通过服务级集成测试：创建任务 → 训练完成 → 评估完成 → 证据包生成。
- Agent 输出候选实验可通过 schema 与审计引用校验，且默认不触发自动建任务。
- LLMGateway 可独立测试（Mock Provider），Provider 切换、限流、重试、成本记录均可验证。
- 知识导入全流程可测试：文档解析 → chunk → LLM 提取 → 冲突检测 → 入库。
- 在线检索可测试：QuerySignature → 候选 Skill → 冲突消解 → SkillContext 生成。
- `next_experiments` 输出含 `skill_refs` 引用，且引用可校验有效。
