# 前端层 Phase 4 开发计划（报告与联调增强）

## 项目概述

本阶段完成决策支持页面：实现 Eval Report / Evidence Pack / Analysis Report / Next Experiments 产物展示页面，完成导出状态与 Deploy Benchmark 查看，确保关键流程端到端可操作，与后端联调脚本口径一致。

**架构设计原则**:
- 产物索引化展示 - 产物数据以索引/摘要形式展示，大文件给出路径/链接而非内嵌
- 决策可视化 - Next Experiments（A/B/C）候选以卡片式对比展示，变更字段与证据引用清晰可见
- 联调可验证 - 页面数据流与 `4.接口层_API联调用例.md` 示例口径完全一致

## 架构验收标准

### 产物展示
- [ ] 四类产物页面（eval/evidence/analysis/next-experiments）查询契约与后端一致
- [ ] 产物不存在时显示明确空态（而非白屏或未处理异常）
- [ ] Markdown 格式的 analysis_report 支持渲染展示

### 候选实验展示
- [ ] A/B/C 候选以卡片或表格形式对比展示
- [ ] 每条候选显示 name/changes/expected/evidence_refs 四要素
- [ ] 可从候选直接跳转 Proposal 确认创建流程（Phase 3 对接）

### 导出与部署基准
- [ ] 导出状态页面支持轮询刷新
- [ ] Deploy Benchmark 指标（时延/吞吐/显存）以表格或图表展示
