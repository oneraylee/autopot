# 前端层 Phase 7 开发计划（LLM Gateway 设置与知识系统 E2E）

## 项目概述

本阶段实现 LLM Gateway 管理页面（Provider 列表、用量报表、调用日志查看），并为知识系统新页面补充 Playwright E2E 冒烟测试，同时更新侧栏导航添加 Settings 入口。

**架构设计原则**:
- 只读管理 - Gateway 页面当前仅提供查看能力（Provider 注册与模型路由通过后端配置文件管理）
- 可视化优先 - 用量报表使用图表展示 token 消耗与成本趋势
- E2E 覆盖 - 知识系统关键流程需有冒烟测试保障

- [x] 用量报表支持按时间范围和分组维度查看
- [x] 调用日志支持分页、筛选（call_type / provider / status）
