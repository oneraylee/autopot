# 前端层 Phase 6 开发计划（知识系统管理页面）

## 项目概述

本阶段为知识库系统构建完整的前端管理界面：包括知识源注册与列表、文档导入与解析状态、技能卡片浏览（按分类/层级/任务类型/成熟度筛选）、技能详情（条件/动作/收益代价/关系图/证据来源）、技能抽取审核（确认/修改/拒绝候选）、冲突检测结果查看与人工仲裁、Skill Taxonomy 树状浏览。

**架构设计原则**:
- 特性目录隔离 - 知识系统页面统一放在 `features/knowledge/` 下，包含 hooks / components / types
- 三态必备 - 所有数据页面处理 loading / empty / error 三态
- 审核流可追溯 - 技能抽取审核与冲突仲裁操作记录可见，操作反馈明确

## 架构验收标准

### 数据请求模式
- [x] 所有知识系统页面使用 TanStack Query hooks，不直接 fetch
- [x] Query key 遵循命名规范（如 `['knowledge', 'sources']`、`['knowledge', 'techniques', techniqueId]`）
- [x] 筛选参数变化时自动重新查询（URL 参数同步）

### 页面结构
- [x] 知识系统入口在侧栏可见（Knowledge 一级导航，含 Sources / Skills / Review 子项）
- [x] 列表页支持多条件筛选（category / layer / task_type / maturity）
- [x] 详情页支持从列表跳转并正确获取路由参数

### 审核与仲裁
- [x] 技能抽取候选列表可展示 LLM 生成的结构体
- [x] 审核操作提供确认 / 修改 / 拒绝三个动作
- [x] 冲突检测结果可展示冲突类型、双方技能摘要、LLM 判定建议
