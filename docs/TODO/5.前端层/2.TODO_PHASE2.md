# 前端层 Phase 2 开发计划（核心读操作页面）

## 项目概述

本阶段打通前端"可查看"链路：实现项目 KPI 配置查看、数据集版本与场景覆盖率查看、任务列表与任务详情（状态/日志/指标）页面，所有页面具备 loading/empty/error 三态，并完成列表到详情的导航闭环。

**架构设计原则**:
- 三态必备 - 每个数据页面必须处理 loading、empty、error 三种状态
- Query 模式复用 - 使用 TanStack Query 统一管理数据请求，标准化加载/错误/缓存/重试
- 模块化特性 - 每个业务域（project/dataset/job）独立 feature 目录，含 hooks/components/types

## 架构验收标准

### 数据请求模式
- [ ] 所有页面使用 TanStack Query hooks 获取数据，不直接 fetch
- [ ] Query key 规范化命名（如 `['projects', projectId, 'kpi-config']`）
- [ ] 错误状态统一展示组件，包含错误码与可读信息

### 页面结构
- [ ] 列表页支持无数据提示与基本状态展示
- [ ] 详情页支持从列表跳转并正确获取路由参数
- [ ] 所有页面使用 shadcn/ui 组件，无原生 HTML 裸样式

### 数据联调
- [ ] API Client 各模块方法（project/dataset/job）类型完整
- [ ] 响应字段与后端 API 路由清单文档一致
