# 前端层 Phase 3 开发计划（核心写操作页面）

## 项目概述

本阶段打通前端"可发起动作"链路：实现 KPI 配置更新、数据集导入/冻结、创建训练任务/启动任务、Proposal 校验与确认创建、创建导出任务的表单页面，所有表单具备校验反馈与成功/失败提示，完成"查 → 提 → 看"交互闭环。

**架构设计原则**:
- 表单校验前置 - 使用 React Hook Form + Zod 在前端先行校验，减少无效请求
- 操作反馈明确 - 成功操作跳转目标页或显示 toast；失败显示后端错误信息
- 乐观更新谨慎 - 写操作不做乐观更新，等待后端确认后再刷新 Query 缓存

## 架构验收标准

### 表单基础设施
- [ ] 所有表单使用 React Hook Form 管理状态，Zod 定义校验 schema
- [ ] 校验失败信息中文可读，定位到具体字段
- [ ] 提交时禁用按钮防止重复提交

### 写操作闭环
- [ ] 成功提交后刷新关联列表页数据（invalidateQueries）
- [ ] 失败时展示后端 error.message 与 error.code
- [ ] 关键写操作有确认弹窗（冻结版本、确认创建 Proposal 任务）

### 与后端契约对齐
- [ ] 请求体字段与后端 API 路由清单严格一致
- [ ] 前端 Zod schema 约束不弱于后端校验规则

## 开发步骤与测试用例

| 子任务 | 输入 | 输出 | 依赖 | 测试用例 |
|---|---|---|---|---|
| P3-1 定义表单 Zod Schemas | 后端请求体字段清单 | `src/schemas/kpi-config.ts`、`job.ts`、`dataset.ts`、`proposal.ts`、`export.ts` | Phase 1 types | schema 能拒绝非法输入；通过合法输入；边界值处理正确 |
| P3-2 实现 KPI 配置更新表单 | PUT kpi-config 接口 | KpiConfigForm 组件 + 页面更新 | P3-1, Phase 2 KPI 页面 | 权重之和校验（eval + deploy）；阈值范围校验；提交成功后页面刷新展示最新值 |
| P3-3 实现数据集导入表单 | POST import 接口 | ImportForm 组件 + 数据集列表更新 | P3-1, Phase 2 数据集列表 | version 必填且为正整数；manifest_uri 格式校验；导入成功后列表可见新版本 |
| P3-4 实现数据集版本冻结操作 | POST freeze 接口 | 冻结按钮 + 确认弹窗 | Phase 2 数据集详情 | 冻结前弹出确认；冻结成功后按钮禁用并显示"已冻结"；重复冻结显示 CONFLICT 错误 |
| P3-5 实现场景标签写入表单 | PUT scene-labels 接口 | 标签编辑组件 | P3-1, Phase 2 数据集详情 | 批量写入多条标签；`weather=other` 时 `weather_other_text` 必填；枚举外值拒绝 |
| P3-6 实现创建训练任务表单 | POST /jobs 接口 | CreateJobForm 组件 + 页面 | P3-1, Phase 2 任务列表 | job_id/task_type/dataset_version_id 必填；gpu_count > 0 校验；提交成功跳转详情页 |
| P3-7 实现任务启动操作 | POST /jobs/{id}/start 接口 | 启动按钮 + GPU 选择 | Phase 2 任务详情 | gpu_id 必填；启动成功状态变更为 RUNNING；状态不允许启动时报错提示 |
| P3-8 实现 Proposal 校验页面 | POST validate 接口 | `/proposals` 页面 + 校验表单 | P3-1, Phase 2 API Client | 提交校验数据后展示 accepted 数量；校验失败展示后端错误详情 |
| P3-9 实现 Proposal 确认创建操作 | POST create-from-candidate 接口 | 确认按钮 + 确认弹窗 | P3-8 | 必填 candidate/baseline_job_id/who/when/confirmed；确认后创建新任务并跳转；幂等 key 复用不报错 |
| P3-10 实现创建导出任务表单 | POST /exports 接口 | CreateExportForm 组件 + 页面 | P3-1, Phase 2 API Client | job_id/run_id/backend 必填；backend 当前仅支持 tensorrt；提交成功跳转导出列表 |
| P3-11 封装通用 Mutation Hook 模式 | 多表单复用需求 | `src/lib/query/useMutationWithToast.ts` | P3-2~P3-10 | 成功显示 toast；失败显示后端错误消息 toast；loading 时按钮 disabled |
