# 前端层 Phase 1 开发计划（工程初始化与基础框架）

## 项目概述

本阶段完成前端工程骨架搭建：初始化 Next.js 14 + TypeScript + Tailwind + shadcn/ui 项目，配置开发工具链，建立全局布局（侧栏导航 + 顶栏 + 内容区），实现 API 基础客户端与统一错误处理，确保"工程可启动、路由可访问、请求可发出"。

**架构设计原则**:
- 目录约定优先 - 遵循 Next.js App Router 目录规范，页面结构即路由结构
- 请求集中化 - 所有 API 调用统一收口至 `src/lib/api`，不允许页面内裸 `fetch`
- 契约对齐 - 前端响应类型与后端统一响应结构 `{ok, data/error}` 严格对齐
