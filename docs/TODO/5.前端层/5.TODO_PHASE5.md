# 前端层 Phase 5 开发计划（质量与发布准备）

## 项目概述

本阶段完成前端最终交付准备：编写 Playwright E2E 冒烟用例覆盖关键业务流程、修复页面可用性问题、补全启动/联调/验收文档，确保非开发人员可按文档完成端到端演示。

**架构设计原则**:
- 冒烟优先 - E2E 测试覆盖关键业务流程而非边角细节，确保"能不能用"
- 选择器稳定 - Playwright 选择器基于 data-testid / role 等稳定属性，不依赖样式 class
- 文档可操作 - 所有文档假设读者为非开发人员，给出可直接运行的命令

## 架构验收标准

### E2E 测试
- [ ] 至少 5 条 Playwright 冒烟用例通过
- [ ] 用例覆盖核心业务流程：数据集导入 → 任务创建 → 任务详情 → 产物查看 → 候选确认
- [ ] 测试失败时自动截图，便于问题定位

### 可用性修复
- [ ] 所有页面无白屏、无未处理异常
- [ ] 关键操作反馈时间 < 3s（网络正常情况下）
- [ ] 移动端基本可访问（不崩溃、关键信息可见）

### 文档完整性
- [ ] README 包含启动命令、环境要求、联调步骤
- [ ] 演示流程文档可指导非开发人员完成一次端到端操作
- [ ] E2E 测试运行命令与预期结果有文档说明
