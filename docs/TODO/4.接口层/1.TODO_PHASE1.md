# 接口层 Phase 1 开发计划（项目/KPI 配置 + 数据集与场景标签 API）

## 项目概述

本阶段完成接口层最小业务入口：项目 KPI 配置管理接口、数据集导入与版本冻结接口、场景标签写入与统计查询接口，确保“配置→数据→统计”链路在 API 层可用且错误结构统一。

**架构设计原则**:
- 契约优先 - 请求/响应结构先于业务实现固化，统一校验与错误返回
- 依赖反转 - 路由仅依赖服务层接口，不直接访问仓储或文件系统
- 可追溯 - 所有写操作保留审计字段（who/when/source）

## 架构验收标准

### 分层与边界
- [ ] `src/api/project_routes.py` 与 `src/api/dataset_routes.py` 不包含业务计算逻辑，仅做参数转换与响应封装
- [ ] 参数校验、业务异常、系统异常都映射为统一错误响应结构

### 接口契约
- [ ] 项目 KPI 配置查询/更新接口支持权重与阈值校验
- [ ] 数据集导入、版本冻结、场景标签写入、统计查询接口语义稳定

### 可测性
- [ ] API 测试具备正向、边界、异常三类覆盖
- [ ] 错误码与附录建议集合一致（DATA_INVALID 等）
