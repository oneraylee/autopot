# 接口层 Phase 2 开发计划（任务编排 + 评估/证据包/LLM 产物查询 API）

## 项目概述

本阶段打通接口层主流程中段：任务创建与状态查询、日志与指标摘要查询，以及评估报告/证据包/LLM 分析产物读取接口，形成“训练→评估→分析”可观察链路。

**架构设计原则**:
- 状态机一致 - API 状态流转严格对齐系统架构状态机
- 读写分离 - 写接口聚焦任务动作，读接口聚焦状态与产物查询
- 产物索引化 - 返回路径/ID 索引，避免直接传输大对象

## 架构验收标准

### 任务状态机对齐
- [x] 任务状态查询与状态码映射覆盖 CREATED/QUEUED/RUNNING/.../LLM_DONE
- [x] 非法状态流转返回稳定错误码（如状态冲突）

### 产物查询一致性
- [x] `eval_report`、`evidence_pack`、`analysis_report`、`next_experiments` 查询契约一致
- [x] 产物不存在、产物格式错误、任务未到达对应阶段时返回明确错误

### 可观测性
- [x] 日志与指标摘要查询支持分页/时间窗口（或等效过滤）
- [x] 错误响应可区分 TRAIN/EVAL/LLM 失败类别
