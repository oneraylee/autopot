# Common库 Phase 3 开发计划（路径规范与产物索引工具）

## 项目概述

本阶段统一 `run_dir` 产物路径组织与索引规则，确保训练、评估、证据、LLM、导出产物在跨服务调用时可预测、可定位、可追踪。

**架构设计原则**:
- 路径标准化 - 统一目录结构与拼装策略
- 读写分离 - 索引对象负责定位，不承担业务计算
- 向后兼容 - 保持可扩展目录层次（新增 backend/runner 不破坏既有路径）

## 架构验收标准

### 目录规范
- [x] 覆盖 `weights/eval/evidence/llm/export` 五类核心目录
- [x] 对文件级别关键产物提供稳定 getter（如 `eval_report.json`）

### 索引一致性
- [x] 同一 `run_id` 在不同服务内获得一致绝对/相对路径
- [x] 非法路径片段（空值、穿越路径）被拒绝
