# Common库 Phase 4 开发计划（跨服务 DTO 与契约对象）

## 项目概述

本阶段沉淀跨服务共享 DTO：`JobSpec`、`ProjectKpiConfig`、`EvalSummary` 等，作为 Core API、Runner、Eval、Agent 之间的稳定数据契约层，降低接口漂移风险。

**架构设计原则**:
- 契约集中管理 - 共享对象统一在 Common 定义
- 前向兼容 - 字段新增可选化，避免破坏性变更
- 显式边界 - DTO 不包含业务动作，只描述数据

## 架构验收标准

### 契约完整性
- [x] `JobSpec` 覆盖模块设计文档中的核心字段
- [x] `ProjectKpiConfig` 支持权重、阈值、聚合策略
- [x] `EvalSummary` 对接 `EvalReport` 关键指标抽象

### 跨层一致性
- [x] API 层与 Runner 层使用同一 DTO（无重复声明）
- [x] DTO 与 Phase 2 校验器可组合使用
