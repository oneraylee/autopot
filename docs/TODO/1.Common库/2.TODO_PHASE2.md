# Common库 Phase 2 开发计划（核心 JSON Schema 校验器）

## 项目概述

本阶段提供 `EvalReport`、`EvidencePack`、`NextExperiments` 三类结构化对象的统一校验入口，保证评估输出、证据包和实验建议可审计、可执行、可回放。

**架构设计原则**:
- 契约优先 - 先有 schema 约束，再接入上下游
- 错误可诊断 - 校验失败必须返回稳定错误结构
- 轻耦合 - 校验器不依赖具体存储与服务实现

## 架构验收标准

### 契约完整性
- [ ] 覆盖附录要求的必填字段与关键嵌套结构
- [ ] 对缺失字段、类型不匹配、非法枚举值给出一致错误格式

### 审计与可执行性
- [ ] `NextExperiments` 校验 `changes`、`expected`、`evidence_refs` 最小闭包
- [ ] `EvidencePack` 能校验 KPI 权重/阈值与索引路径字段

## 开发步骤与测试用例

| 子任务 | 输入 | 输出 | 依赖 | 测试用例 |
|---|---|---|---|---|
| P2-1 定义统一校验错误结构 | 附录错误码建议 | `ValidationErrorDetail` | Phase 1 | 缺字段/类型错/枚举错均返回同结构 |
| P2-2 实现 `validate_eval_report` | EvalReport 约束 | EvalReport 校验入口 | P2-1 | `overall.business_kpi` 缺失失败；`by_scene` 类型错误失败 |
