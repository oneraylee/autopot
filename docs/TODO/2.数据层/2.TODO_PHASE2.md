# 数据层 Phase 2 开发计划（场景标签与覆盖率统计仓储）

## 项目概述

本阶段聚焦场景维度标签落库与统计查询能力，支撑数据集质量分析、按场景切片 KPI 分析与 LLM 证据引用。目标是提供“可写入、可聚合、可解释”的场景数据底座。

**架构设计原则**:
- 先契约后聚合 - 先稳定标签字段契约，再扩展统计接口
- 统计与原始分离 - 原始标签写入与统计查询职责分离
- 维度可扩展 - 支持新增维度不破坏既有查询语义

## 架构验收标准

### 分层设计
- [ ] 标签写入与统计查询均通过 `SceneLabelRepository` 暴露，不在业务层拼接 SQL/聚合逻辑
- [ ] 统计接口输出与 Eval 报告 `by_scene` 对齐，便于后续证据关联

### 核心组件
- [ ] 支持 `SceneLabel` 单条/批量写入与更新
- [ ] 支持按单维度与组合维度计算覆盖率统计

### 统一接口
- [ ] 统计查询支持标准筛选（dataset_version_id、维度集合、是否含 unknown）
- [ ] `weather=other` 场景支持 `weather_other_text` 扩展字段
