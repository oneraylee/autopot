# 数据层 Phase 3 开发计划（任务状态事件与产物索引仓储）

## 项目概述

本阶段完成训练任务链路的数据层收口：实现 Job 元数据、状态流转事件、资源占用记录与产物索引持久化，确保“状态可审计、产物可定位、错误可追踪”。

**架构设计原则**:
- 状态机约束内置 - 在仓储层阻断非法状态跃迁
- 事件先于快照 - 通过事件流记录状态变化，再维护任务摘要
- 产物索引规范化 - 使用路径/ID 索引大文件，不在元数据中塞入大对象

## 架构验收标准

### 分层设计
- [ ] `JobRepository` 与 `ArtifactRepository` 作为唯一任务/产物元数据入口
- [ ] 业务层通过统一仓储接口完成状态迁移与产物登记

### 核心组件
- [ ] `JobRepository` 支持 Job 创建、状态迁移、事件记录、资源占用持久化
- [ ] `ArtifactRepository` 支持 run 产物索引（权重、评估、证据包、LLM 输出、导出产物）

### 统一接口
- [ ] 非法状态流转返回统一错误码（对齐 Common 错误码）
- [ ] 产物索引路径命名统一、可按 `job_id/run_id` 查询
