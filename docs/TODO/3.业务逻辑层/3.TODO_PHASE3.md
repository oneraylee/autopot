# 业务逻辑层 Phase 3 开发计划（导出服务与服务级集成验收：ExportService + E2E Flow）

## 项目概述

本阶段完成业务逻辑层最后一环：实现 TensorRT 导出服务与部署基准 JSON 产出，并将部署指标按项目配置并入业务 KPI；同时通过服务级集成测试验证“创建任务 → 训练完成 → 评估完成 → 证据包生成”主流程。

**架构设计原则**:
- 扩展优先 - 导出后端采用可扩展枚举与适配器结构
- 指标闭环 - 部署基准与训练评估指标统一汇总到业务 KPI
- 集成可验证 - 关键主链路必须由服务级集成测试覆盖

## 架构验收标准

### 分层设计
- [ ] `ExportService` 通过 Job/Artifact/KPI 接口协作，不直接依赖底层执行细节
- [ ] 服务级集成测试在服务边界验证流程，不穿透到 UI 层

### 核心组件
- [ ] `ExportService` 支持导出任务管理与 `deploy_benchmark.json` 产出
- [ ] KPI 汇总逻辑支持按项目配置将时延/吞吐等部署指标纳入加权
- [ ] 集成测试覆盖训练后主链路关键状态与产物

### 统一接口
- [ ] 导出规格 `ExportSpec` 支持 backend 枚举扩展（当前 TensorRT）
- [ ] 导出失败统一映射 `EXPORT_FAILED` 并保留 stderr/stdout 线索
