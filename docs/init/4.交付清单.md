# 交付清单.md

## 1. 代码与服务
### 1.1 Core Platform（必须）
- Core API Service（项目/数据集/任务/产物/评估/证据包）
- LocalRunner（Docker + GPU 调度）
- Eval Runner（Python 脚本执行器 + JSON 校验）
- Evidence Pack Builder
- Web UI（基础页面：项目、数据集、任务列表、任务详情、对比、LLM 报告、A/B/C）
- Frontend 工程（Next.js + TypeScript + Tailwind + shadcn/ui + Query 层）

### 1.2 LLM Gateway（必须）
- Provider Registry（支持 OpenAI / 智谱 / Ollama / 其他 OpenAI 兼容 API）
- Model Router（按任务类型路由到不同 Provider + Model）
- Embedding Provider（云端 / 本地可切换，Phase 1 可不启用）
- Cost Tracker（token 用量、成本估算、调用日志 llm_call_log）
- Rate Limiter（按 Provider 配置 RPM/TPM）
- Gateway 配置管理 UI（Provider 选择、模型路由配置）

### 1.3 LLM Agent Service（必须）
- Agent Orchestrator（经 LLM Gateway 调用 LLM）
- Tool/Function Calling 适配层（调用 Core API）
- 输出落库/落盘（analysis_report.md、next_experiments.json）
- Prompt/Policy（证据驱动、可审计、输出 JSON schema）

### 1.4 Knowledge System（必须）
- Knowledge Ingestion（文档解析 Pipeline：Markdown / HTML / PDF / Notebook / Code → chunk）
- 半自动技能抽取（经 LLM Gateway 调用 LLM + 人工确认）
- 导入时冲突检测（经 LLM Gateway 分析 + 人工判定）
- Knowledge Registry（Skill Card CRUD、四大分类管理、版本/条件/动作/关系/模板）
- Retrieval Service（结构过滤 + 规则召回 + 关键词检索，Phase 3+ 加向量检索）
- Conflict Resolution Service（冲突消解 + 资源预算校验 + 版本兼容校验）
- Strategy Composer（最小上下文生成 + planning_snapshot 审计）
- Skill Outcome Tracker（内部经验闭环）
- 知识库管理 UI（Skill Card 浏览/搜索/审核、来源管理、冲突图谱）

### 1.5 Export Service（P1）
- TensorRT 导出流水线（ONNX→TRT）
- 部署基准测试（时延/吞吐/显存）输出 JSON

## 2. 数据与存储
- Metadata DB：项目、KPI 配置、数据集/版本、场景标签、任务、指标摘要、产物索引
- Knowledge DB：Skill Card、条件、动作、关系、证据、模板、outcome、planning_snapshot、llm_call_log
- Artifact Storage：NAS/MinIO（run_dir、权重、评估报告、证据包、LLM 输出、导出产物、原始知识文档归档）
