# readme描述.md

## 项目名称
图像算法训练平台（YOLO11 + LLM Agent 智能分析闭环）

## 目标
构建一个面向图像算法训练的一体化平台，覆盖：
1. **模型训练**：支持 YOLO11 系列的分类/检测/实例分割训练，支持单机多卡并行、断点续训、AMP、量化流水线（以 TensorRT 为当前目标后端）。
2. **智能分析与迭代闭环**：引入云端 LLM，以 **Agent（函数调用）** 方式解耦接入，在数据集导入完成后即对数据集内容、场景覆盖、类别分布、数据质量以及用户填写的业务描述进行多维分析，生成多套训练建议与方案；在训练完成后继续结合训练指标、评估结果和业务 KPI 生成下一轮优化方案。
3. **知识系统与技能卡片**：将 YOLO 训练技巧、数据处理经验、模型改造方案等结构化为**技能卡片（Skill Card）**，通过知识系统在分析和诊断时自动注入相关领域知识，提升 Agent 建议的专业性与可落地性。

> 默认策略：数据集导入完成后，LLM Agent 先生成候选训练方案；用户确认方案后，系统**自动创建草稿 Job**；Job 在用户再次确认执行后才进入实际训练。

## 范围（当前版本）
- 部署环境：**本地机房**
- 算力：**单机多卡（NVIDIA 4090 24GB / 48GB）**
- 数据标注格式：**YOLO**
- 任务范围：**收敛在 YOLO11 系列**
- 场景维度标签：人工下拉 + “其它”文本输入（需要结构化存储）
- 指标：以**业务 KPI（多指标加权）**为主，权重按项目配置
- 测试脚本：Python 脚本，输出规范 JSON

## 非目标（当前版本不做）
- 多租户/复杂权限隔离（但保留按项目配置能力）
- 多机分布式训练（架构预留 Runner 抽象，后续可扩展）
- 多推理后端（当前只做 TensorRT，后续扩展）

## 关键理念
- **平台主体（Core）与 LLM Agent 解耦**：Agent 只能通过 API/函数调用交互，不直接访问 DB/文件系统。
- **证据先行（Evidence Pack）**：平台负责结构化/摘要化，Agent 基于证据推理并输出可执行实验计划 JSON。
- **行动可审计**：所有建议与实验计划必须能回溯到证据字段（数据/训练/评估/场景切片）。
- **LLM Gateway 统一管控**：所有 LLM 调用（Agent 推理、知识提取、冲突分析、Embedding）统一经过 Gateway 层，实现 Provider 可插拔、模型按任务路由、成本可追踪。
- **离线重加工，在线轻推理**：知识系统在导入阶段完成文档解析→分块→技能卡片提取（重计算），在线阶段仅做结构化检索+轻量排序（轻推理）。
- **技能卡片（Skill Card）驱动**：训练/数据/模型/评估领域的经验以技能卡片形式标准化管理，按分类法（Taxonomy）组织，确保知识可检索、可组合、可追溯。

## 快速上手（开发态示例）
1. 导入数据集（YOLO 格式）并创建数据集版本
2. 为数据集补充业务描述、任务目标、约束条件与场景维度标签（昼夜/天气/室内外/相机位点等）
3. 平台生成数据集证据包，知识系统自动检索匹配的技能卡片注入上下文，调用 LLM Agent 输出：
  - `dataset_analysis_report.md`
  - `training_plan_candidates.json`（多套训练方案，含训练参数、YOLO backbone/neck/head 选择建议，附 `skill_refs` 引用）
4. 用户在 UI 确认其中一个训练方案，平台自动创建草稿训练 Job
5. 用户确认执行后，Job 开始排队并启动训练
6. 训练完成后自动执行评估脚本，生成 `eval_report.json`
7. 平台生成 `evidence_pack.json`，知识系统再次注入诊断相关技能卡片，调用 LLM Agent 输出：
  - `analysis_report.md`
  - `next_experiments.json`（下一轮优化 A/B/C，附 `skill_refs` 引用）
8. （可选）管理员导入知识文档（Markdown/PDF/Notebook/代码），系统自动解析→分块→LLM 提取技能卡片→冲突检测→入库

## 目录结构（建议）
- `/datasets/<dataset_id>/<version_id>/...`
- `/runs/<job_id>/`
  - `weights/` (`best.pt`, `last.pt`)
  - `train_args.json`
  - `train_logs/`
  - `plots/`
  - `pred_samples/`
  - `eval/eval_report.json`
  - `evidence/evidence_pack.json`
  - `llm/analysis_report.md`
  - `llm/next_experiments.json`
  - `export/tensorrt/`（可选）
- `/datasets/<dataset_id>/<version_id>/analysis/`
  - `dataset_analysis_report.md`
  - `training_plan_candidates.json`
- `/knowledge/`
  - `raw/<source_id>/`（原始知识文档）
  - `chunks/<source_id>/`（分块结果）
  - `import_logs/`（导入日志）

## 里程碑（MVP 优先）
- M1：数据导入后 Agent 训练方案生成（数据分析→方案确认→草稿 Job→执行确认）
- M2：训练闭环（数据→训练→评估 JSON→可视化）
- M3：LLM Agent 训练后诊断 + A/B/C 候选实验（人点选）
- M3.5：LLM Gateway + 知识系统 Phase 1（Gateway 统一管控 + 知识导入 + 技能卡片半自动提取 + 冲突检测 + 结构化检索注入 Agent 上下文）
- M4：HPO（后续，暂不做）
- M5：TensorRT 导出与部署基准评测（逐步增强）
- M6：知识系统 Phase 2+（语义向量检索 + 技能效果追踪 + 自动权重调整）

## 术语
- Core Platform：训练平台主体服务
- LLM Agent Service：智能分析服务（云端大模型 + 工具调用）
- LLM Gateway：LLM 调用统一网关（Provider 可插拔、模型路由、成本追踪）
- Knowledge System：知识系统（知识导入→技能卡片提取→检索→上下文注入）
- Skill Card（技能卡片）：将训练技巧、数据处理经验等结构化为标准卡片，含适用条件、操作步骤、副作用、来源
- Skill Taxonomy：技能分类法，四大类（Training / Model / Data / Eval&Deploy），层级编码如 `train.augment.mosaic_scale`
- Evidence Pack：证据包（结构化 JSON）
- Business KPI：多指标加权 KPI（按项目配置）
