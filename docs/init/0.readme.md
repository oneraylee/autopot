# readme描述.md

## 项目名称
图像算法训练平台（YOLO11 + LLM Agent 智能分析闭环）

## 目标
构建一个面向图像算法训练的一体化平台，覆盖：
1. **模型训练**：支持 YOLO11 系列的分类/检测/实例分割训练，支持单机多卡并行、断点续训、AMP、量化流水线（以 TensorRT 为当前目标后端）。
2. **智能分析与迭代闭环**：引入云端 LLM，以 **Agent（函数调用）** 方式解耦接入，对训练参数、数据集构成、训练指标、业务 KPI 进行证据驱动分析，自动生成 **候选实验 A/B/C**，由用户一键选择发起下一轮训练。

> 默认策略：LLM Agent **只生成候选实验**，不自动创建训练任务。

## 范围（当前版本）
- 部署环境：**本地机房**
- 算力：**单机多卡（NVIDIA 4090 24GB / 48GB）**
- 数据标注格式：**YOLO**
- 任务范围：**收敛在 YOLO11 系列**
- 场景维度标签：人工下拉 + “其它”文本输入（需要结构化存储）
- 指标：以**业务 KPI（多指标加权）**为主，权重按项目配置
- 测试脚本：Python 脚本，输出规范 JSON

## 非目标（当前版本不做）
- 多租户/复杂权限隔离（但保留按项目配置能力）
- 多机分布式训练（架构预留 Runner 抽象，后续可扩展）
- 多推理后端（当前只做 TensorRT，后续扩展）

## 关键理念
- **平台主体（Core）与 LLM Agent 解耦**：Agent 只能通过 API/函数调用交互，不直接访问 DB/文件系统。
- **证据先行（Evidence Pack）**：平台负责结构化/摘要化，Agent 基于证据推理并输出可执行实验计划 JSON。
- **行动可审计**：所有建议与实验计划必须能回溯到证据字段（数据/训练/评估/场景切片）。

## 快速上手（开发态示例）
1. 导入数据集（YOLO 格式）并创建数据集版本
2. 为图片补充场景维度标签（昼夜/天气/室内外/相机位点等）
3. 创建训练任务（YOLO11）
4. 训练完成后自动执行评估脚本，生成 `eval_report.json`
5. 平台生成 `evidence_pack.json`，调用 LLM Agent 输出：
   - `analysis_report.md`
   - `next_experiments.json`（A/B/C）
6. 用户在 UI 点选 A/B/C，一键创建下一轮训练任务

## 目录结构（建议）
- `/datasets/<dataset_id>/<version_id>/...`
- `/runs/<job_id>/`
  - `weights/` (`best.pt`, `last.pt`)
  - `train_args.json`
  - `train_logs/`
  - `plots/`
  - `pred_samples/`
  - `eval/eval_report.json`
  - `evidence/evidence_pack.json`
  - `llm/analysis_report.md`
  - `llm/next_experiments.json`
  - `export/tensorrt/`（可选）

## 里程碑（MVP 优先）
- M1：训练闭环（数据→训练→评估 JSON→可视化）
- M2：LLM Agent 训练后诊断 + A/B/C 候选实验（人点选）
- M3：HPO（后续，暂不做）
- M4：TensorRT 导出与部署基准评测（逐步增强）

## 术语
- Core Platform：训练平台主体服务
- LLM Agent Service：智能分析服务（云端大模型 + 工具调用）
- Evidence Pack：证据包（结构化 JSON）
- Business KPI：多指标加权 KPI（按项目配置）
