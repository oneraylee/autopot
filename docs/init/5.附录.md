## B. 场景维度枚举建议

- time_of_day: day / night / dusk / unknown

- weather: clear / rain / snow / fog / other / unknown

- indoor: indoor / outdoor / unknown

- camera_fixed: true / false / unknown

- grayscale: true / false / unknown

- camera_site: site_id（字符串/枚举）

> weather=other 时增加 weather_other_text。

## C. EvalReport JSON Schema（简化说明）

- 必填字段：

  - overall.business_kpi

  - overall.kpi_components

  - by_class[]

  - by_scene[]

  - error_slices[]

  - artifacts{...}

示例（片段）：
```json
{
  "overall": {
    "business_kpi": 0.873,
    "kpi_components": {"漏检率":0.031,"误检率":0.052,"时延ms":18.4}
  },
  "by_scene": [
    {"scene":{"time_of_day":"night","weather":"rain"},"kpi":0.62,"fn":40,"fp":9}
  ]
}
```

## D. Evidence Pack 生成规则（关键）

- 曲线数据：降采样/统计摘要（避免直接塞每 step 原始数据）

- 大文件：只给索引路径（sample_visuals_dir 等）

- 必须合并项目 KPI 配置（权重/阈值）用于 Agent 决策

## E. NextExperiments（A/B/C）输出规范

- 必须提供：

  - name

  - changes（相对 baseline 的变更）

  - expected.kpi_delta（对 KPI 分量的方向/幅度预估，可为区间/定性）

  - evidence_refs（引用 evidence_pack 的字段路径，用于审计）

示例：
```json
{
  "baseline_job_id": "job_001",
  "candidates": [
    {
      "name": "A_提高imgsz以改善小目标夜间FN",
      "changes": {"train_args":{"imgsz":960}},
      "expected": {"kpi_delta":{"漏检率":-0.01,"时延ms":+2}},
      "evidence_refs": ["evaluation.by_scene[night+rain].fn", "dataset.stats.small_object_ratio"],
      "skill_refs": ["train.hyperparameter.increase_imgsz_small_night"],
      "conflict_checked": true,
      "resource_profile": {
        "gpu_mem_gb_required": 20,
        "latency_delta_ms_est": 1.8
      }
    }
  ]
}
```

## F. 训练参数模板建议（4090 24GB/48GB）

- 默认启用 AMP

- batch：平台支持 dry-run 自动探测上限（不同 imgsz/模型规模差异大）

- imgsz：

  - 默认 640

  - 小目标多/夜间多：768/960

- 并行建议：

  - HPO/多实验：每 trial 1 GPU（最大化吞吐）

  - 单实验追精度：多 GPU DDP（可选）

## G. 常见失败原因分类（建议错误码）

- TRAIN_OOM：显存不足

- TRAIN_NAN：loss NaN/发散

- DATA_INVALID：数据格式/标注异常

- EVAL_FAILED：评估脚本异常/JSON不合规

- LLM_FAILED：云端 API 失败/超时/输出不合规

- LLM_GATEWAY_ERROR：Provider 不可用/限流/API Key 无效

- KNOWLEDGE_IMPORT_FAILED：文档解析失败/技能抽取失败

- EXPORT_FAILED：TensorRT 导出失败

## H. 安全与合规（LLM）

- Evidence Pack 脱敏：避免泄露敏感路径/业务信息（按需）

- Agent 只读证据 + 仅通过受控 API 行动

- 默认不自动创建任务（用户确认）

## K. Skill Taxonomy（技能分类体系）

```
Skill Taxonomy
├── Training Skills（训练技能）
│   ├── optimizer      — 优化器选择与配置（SGD/AdamW/LAMB...）
│   ├── schedule       — 学习率策略（cosine/warmup/step decay...）
│   ├── augment        — 数据增强策略（Mosaic/MixUp/CopyPaste...）
│   ├── regularization — 正则化（EMA/dropout/label smoothing...）
│   ├── precision      — 精度策略（AMP/bf16/梯度累积...）
│   ├── freeze         — 冻结策略（backbone freeze/partial unfreeze...）
│   ├── hyperparameter — 超参组合（batch/epoch/imgsz/warmup...）
│   └── distributed    — 分布式策略（DDP/多卡并行/梯度同步...）
│
├── Model Skills（模型架构技能）
│   ├── backbone       — 主干网络选择与改造
│   ├── neck           — 颈部结构（FPN/PAN/BiFPN/GFPN...）
│   ├── head           — 检测头/分割头改造
│   ├── block          — 基础模块替换（C2f→C3/RepConv/Ghost...）
│   ├── attention      — 注意力机制（SE/CBAM/GAM/SimAM...）
│   ├── conv           — 卷积替换（DSConv/DeformConv/SPDConv...）
│   └── loss           — 损失函数（CIoU/WIoU/Focal/VarifocalLoss...）
│
├── Data Skills（数据处理技能）
│   ├── cleaning       — 数据清洗（去重/噪声检测/标注修复...）
│   ├── balancing      — 类别平衡（过采样/欠采样/class weight...）
│   ├── scene_coverage — 场景覆盖优化（场景补采/合成数据...）
│   ├── split          — 数据划分策略（分层/场景感知/时序...）
│   └── preprocessing  — 预处理（归一化/resize策略/padding...）
│
└── Eval & Deploy Skills（评估与部署技能）
    ├── metric         — 评估指标设计（场景切片/长尾评估...）
    ├── calibration    — 模型校准（温度缩放/后处理调参...）
    ├── quantization   — 量化策略（PTQ/QAT/INT8校准...）
    ├── export         — 导出优化（ONNX/TensorRT/剪枝...）
    └── benchmark      — 部署基准（时延/吞吐/显存评估...）
```
